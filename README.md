# unreleaseddots | dots

Portfolio pessoal com tema glitch/dark vermelho-rosa nebulosa para desenvolvedor autodidata focado em low-level, automação e segurança digital.

🌐 **Domínio:** [unreleaseddots.com.br](https://unreleaseddots.com.br)

## 🎨 Características

- **Tema Nebulosa Vermelho/Rosa**: Design cyberpunk inspirado em nebulosas espaciais
- **Paleta de Cores**: Vermelho neon (#ff0055), Rosa vibrante (#ff3366), Rosa nebulosa (#ff6b9d)
- **Efeitos Visuais**: Animações glitch, sobreposições CRT, scanlines rosas, smooth scrolling
- **Totalmente Responsivo**: Funciona em desktop, tablet e mobile
- **Focado em Dev**: Mostra skills técnicas, projetos reais do GitHub
- **Performance**: Leve e rápido
- **Fácil de Customizar**: HTML/CSS/JS simples

## 🚀 Stack Técnico do Site

- HTML5, CSS3, JavaScript Vanilla
- Google Fonts: Fira Code, Share Tech Mono
- Font Awesome Icons
- Imagens geradas programaticamente com Python/PIL
- Tema customizado vermelho/rosa nebulosa
- Sem frameworks ou build tools necessários

## 🎨 Personalização

### Cores (Tema Nebulosa Vermelho/Rosa)

Edite `assets/css/main.css` e modifique as variáveis CSS:

```css
:root {
    --color-bg: #0a0a0f;           /* Fundo principal (preto azulado) */
    --color-bg-alt: #170812;       /* Fundo alternativo (preto roxo) */
    --color-primary: #ff0055;      /* Vermelho neon (primário) */
    --color-secondary: #ff6b9d;    /* Rosa nebulosa (secundário) */
    --color-tertiary: #ff3366;     /* Rosa vibrante (terciário) */
}
```

**Paleta inspirada em nebulosas espaciais vermelhas/rosas**

## ✨ Recursos

### Efeitos Glitch
- Animação glitch no título ao passar o mouse
- Efeitos glitch aleatórios pela página
- Overlay de scanline para visual CRT autêntico

### Tema Terminal
- Fontes monospace (Fira Code, Share Tech Mono)
- Comandos estilo terminal na navegação
- Estética de prompt de comando
- Easter eggs no console (abra o console e digite `help()`)

### Elementos Interativos
- Navegação com smooth scrolling
- Destaque de seção ativa
- Efeitos hover em todos elementos interativos
- Validação de formulário
- Notificações de sucesso/erro

## 🎮 Comandos do Console

Abra o console do navegador e tente estes comandos:

- `help()` - Lista todos comandos disponíveis
- `about()` - Mostra informações sobre
- `skills()` - Exibe skills técnicas
- `projects()` - Abre perfil do GitHub
- `contact()` - Mostra informações de contato
